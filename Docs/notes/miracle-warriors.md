### Night 2026-11-17 (user asleep; user reports + PSRP languages)  *(part; the rest of this section is in another notes file)*

- **Miracle Warriors `[stack]` after a battle (user report, PSG mode) = a recompiler bug, fixed (engine `36f3da4`).** Sound driver bank 15 `$8F60` (command loop): `ld hl,$9066 ; push hl ; sub $F0 ; jp c,$90D9 ; ... jp (hl)`; the `$90D9` path (commands `$E0-$EF`) ends in `ret` (`$90E2`), `jp $947D` (PSG) or `jp $8EEA` (FM), all of which resume at `$9066`. The codegen made `jp c,$90D9` a goto (target inside the function) but the stack dataflow treated it as a call and never followed it, so the RET and both tail jumps returned out of the whole C function (SP 2 too low: `[stack] call at 0x9380 / 0x8A00 / 0x013B ...`). Reproduced with every sound request (`--poke-file` `DD03=81..AF` every 400 frames): sound `$9F` (the battle reward jingle). Fix (function_finder.c / code_generator.c): the dataflow follows `jp cc` into labels of the function (as the codegen does); `trace_tail_jump_cont()`: a `jp` / `jp cc` to ANOTHER function while this function's own constant continuation is on the stack = a call with that continuation (same run-time contract as `push cont ; jp T`); a RET-jump whose constant target is a label of the function = `goto`. Side effect caught by the all-builds diff: during discovery the dataflow then followed PS AGES En bank 32 `$85F0 jp nz,$8748` (`$8748` not yet an entry) and registered `$85F6` as an entry, which broke the existing call form; claims made through a `push cont ; jp cc,T` edge (`DfState.cc`) no longer register entries that are inside the trace (`trace_ret_jump_target_reg`). Generated C of all other 18 builds identical; MW: exactly the 3 sites. Verified: all sounds in PSG and FM mode: 0 `[stack]`; lockstep `rand1` final SAME; the all-sounds lockstep ends with ONE differing RAM byte (`$DFF2`, the IRQ-pushed PC = timing). MW in PSG mode was never soaked before today's PSG default: that is why this was not seen earlier. Tool: `sh Tools/regen_all.sh <outdir>` regenerates every game into a scratch folder (compare two recompilers with `diff -r`).
