# CLAUDE.md — Phantasy Star (SMS) PC Remake with SEGA AGES-style QoL

Project-level notes. The engine repo has its own `smsggrecomp/CLAUDE.md` + `PRINCIPLES.md`
(read those before touching the recompiler). **Never commit without explicit user instruction.**

## Goal

Native PC build of the 1987 Phantasy Star (Sega Master System) made by **static recompilation**
of the Z80 ROM to C (mstan's `smsggrecomp`), then add SEGA-AGES-style quality-of-life features
in C/SDL2 on top (first: a real-time 2D dungeon auto-map overlay; later: speed/encounter/XP
options, FM audio).

Base ROM = **original Rev A**. The SEGA AGES ROM is only a comparison/diff target.

## Multi-ROM workflow (2026-11-12)

One recompiled build per ROM, each in `Games/<slug>/`, made by a generator so it is reproducible:
```
python -I Tools/mkgame.py <slug> "<file in ROMs/>" "<window title>" [--template ps_reva|sonic1|sms_generic] [--hooks ps|none]
        [--auto-tables]                     # PS only: detect [jump_tables] with Tools/ps_find_tables.py
        [--byte-table ADDR:BANK:COUNT:PAGE] [--table-count ADDR=N] [--banked ADDR:BANK]
Games/<slug>/build.ps1                      # recompile ROM -> C, build the runner (needs recompiler/build/SmsRecomp.exe)
Games/<slug>/check.ps1 -Frames 20000 -Press ..\Common\PhantasyStar\cmp\rand1.txt   # headless soak, lists dispatch misses
Games/<slug>/play.ps1 [-Scale 3] [-Speed 1.0]   # saves go to Games/<slug>/saves/ (env SMS_SAVE_DIR, new)
sh Tools/verify_game.sh <slug>              # build + compare recompiled vs --interp frames on a scripted input
```
`game.toml` `rom = "../../ROMs/<file>"` (relative to the game folder; `CMakeLists` default `SMSGG_ROOT = ../../Recomp/smsggrecomp`).
Every generated build is tied to its ROM's CRC32 (the runner refuses another ROM). Idea for the launcher app: scan `ROMs/`, CRC32 -> slug, create `Games/<slug>` with mkgame on first use, build, run; a PowerShell menu first, an SDL list later.

**Path gotcha:** the project path contains `#` (`#Patrik`): never use `#` as a sed delimiter, always quote paths (spaces too) in shell scripts.

### Diagnostic build + differential harness (very useful)
`build_diag/` = reference execution, no GPU, `-DSMS_TRACE_PC`:
```
cmake -S . -B build_diag -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_C_COMPILER=C:/msys64/mingw64/bin/gcc.exe \
  -DCMAKE_MAKE_PROGRAM=C:/msys64/mingw64/bin/ninja.exe -DCMAKE_PREFIX_PATH=C:/msys64/mingw64 -DSMSGG_ROOT=<abs path to smsggrecomp> \
  -DSMSGG_REGENERATE=OFF -DSMSGG_NATIVE_EXECUTION=OFF -DSMSGG_ENABLE_GPU=OFF "-DCMAKE_C_FLAGS=-DSMS_TRACE_PC"
```
Env vars (run `build_diag\PhantasyStarSMSRecomp.exe ..\phantasystar.sms --frames N`):
- `SMS_RAM_WATCH=<hexaddr>|ALL` + `SMS_RAM_WATCH_FRAME=n` -> log writes with call chain.
- `SMS_DIFF_ADDR=<hex,hex,...>` (<=256) + `SMS_DIFF_LO/HI=<frames>` + `SMS_DIFF_MAX=1` -> per-function recomp-vs-interpreter state diff; prints `DIVERGES` with regs/RAM.
- `SMS_DIFF_TRACE=1` -> also pinpoints first divergent instruction / prints stream tails (I added the tails print in `runner/glue.c`).
The function list for SMS_DIFF_ADDR: `grep -o -E "func_[0-9A-F]{4}" generated/ps1sms_funcs.h`.

## SEGA AGES ROM analysis (done 2026-11-11)

`Phantasy Star (World) (En) (Sega Ages).sms` (540,672 B = 33 banks) is **Rev A + FM sound only**, no gameplay/QoL changes:
- Banks 0-31 identical to Rev A except **28 bytes in bank 0**: `$0010-$0025` (was `$FF` padding) holds a stub that does `... out ($F2),1` (enable the YM2413 FM unit) then `jp $02ED`; `jp $02ED` at `$00A2` became `jp $0010`; the 4 sound-call shims at `$02E9/$02EB/$02F1/$02F9` select **bank `$20` (new bank 32) and entry `$8052`** instead of bank 12 / `$8043`.
- Bank 32 (16 KB, at `$80000`) = a new sound driver (channel structs at `$C00E`, 10 channels = 6 FM melodic + 4 PSG-ish) that writes the YM2413 via ports `$F0` (reg) / `$F1` (data) / `$F2` (control).
- So the AGES soundtrack = FM music + the original PSG SFX. Everything else (game logic, graphics) is the original code.

## Gotchas learned

- The engine keys code by `(bank, addr)`; `[jump_tables] bank` is the bank mapped at that address (slot-2 tables use the slot-2 bank, e.g. 12 for `$82E5`).
- "entry trail" addresses in `dispatch_misses.log` are function entry ids (e.g. `0008` = `rst_08` VDP-address helper), not necessarily where the bad jump came from.
- After editing the recompiler: rebuild `smsggrecomp/recompiler/build`, then `run_loop.ps1` (it regenerates). Never edit `generated/*.c`.
- Python/heredoc edits of C source: `\n` inside C string literals gets mangled; prefer the Edit tool.
